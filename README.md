# Katalog części rowerowych

Prosta aplikacja webowa z listą części do serwisu rowerowego.

Autor: Piotr Bacior, indeks 63899.

## Uruchomienie

Potrzebny jest .NET SDK 8.

    dotnet test
    dotnet run --project BikePartsApi

Adres strony wypisze konsola. Lista części w JSON jest pod ścieżką /products.

## Repozytorium

Zmiany wchodzą przez pull request do main. Zadania są na tablicy Project.
